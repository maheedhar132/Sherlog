# Security policy

Sherlog is a static, client-side game. It has no backend, no accounts and no network calls, and it stores your profile only in your own browser's `localStorage`.

## Supported versions

Only the latest release on `main` (the version deployed on the live site) receives fixes.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through [GitHub's private vulnerability reporting](https://github.com/maheedhar132/Sherlog/security/advisories/new).

Include steps to reproduce and the impact. You'll get a response within 7 days. Once a fix ships, you'll be credited in the release notes unless you'd rather not be.
