# Code of Conduct

Sherlog follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be welcoming and respectful, whatever someone's experience level, background or identity.
- Critique code and ideas, never people. Blameless, like a good postmortem.
- No harassment, insults or personal attacks, in public or in private.
- Maintainers may remove comments, commits or contributors that break these rules.

## Reporting

Report unacceptable behaviour privately to the maintainer through a [GitHub security advisory](https://github.com/maheedhar132/Sherlog/security/advisories/new) (it stays private), or by contacting [@maheedhar132](https://github.com/maheedhar132) directly. Every report is reviewed and kept confidential.
